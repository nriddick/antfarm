# Ant Farm 1.9.0

Ant Farm 1.9.0 simplifies the Farm to single-shot payloads, adds C ABI 1 and
C++ ownership adapters, and extends public and private actors to native C/C++
applications. This release includes the work from the unpublished 1.8.3
development branch and introduces breaking D API changes.

## Highlights

- **Single-shot work with completion joins.** MT payloads and their full
  in-ring headers are removed. Independent entries still run across multiple
  consumers. Every write form supports a completion hook that joins all
  accepted payload callbacks. Grain-based range helpers handle parallel work
  and its final partial grain.
- **C ABI 1, with explicit runtime separation.** The BetterC static core,
  public actors, private actors and actor waves work without druntime.
  A separate optional library exposes the non-Fiber FarmHost worker pool,
  with explicit D runtime initialization and thread attachment. C++ adapters
  provide move-only ownership. Fiber exports remain deferred; D Fiber support
  remains available.
- **Native actor storage and batching.** Runtime-owned actor kinds describe
  handlers and state layout once. Copy and init callbacks construct directly
  in final storage. The API provides 16-byte value owners, caller-owned inbox
  messages, strided batch operations and waves. Private actors expose tracked
  roots, cancellation, deadlines, outcomes, cohorts, result ports, subset waves
  and continuations. Optional root state slabs avoid per-spawn allocations.
- **Scheduling and tooling improvements.** Specialized writer sizing loops,
  FIFO preservation through partial root admission, and lifecycle improvements
  reduce overhead. Host stepping batches emission and wakes parked workers on
  backpressure. Native Windows benchmark imports, C actor benchmark options,
  and generated Fiber throughput reporting are corrected.

## Migrating from 1.8.x

- Replace MT payload iteration with independent entries or
  `payloadRange!fn(source, grain)`. Grain must be positive; retain referenced
  data through completion. `parallelSlices` and `ParallelForm` are removed.
- Replace `PayloadHeader`, `initPayloadHeader` and `payloadEntryRuntime` with
  `PayloadEntry`, `payloadEntry!fn(...)` or `callbackFor!fn()`. Callbacks now use
  C linkage and a body pointer plus length. MT controls such as `maxCs`, `done`
  and `pcount` are removed.
- Replace `writeTracked` with `write`, passing its optional completion hook
  after the token and cost class. Partial writes join only the accepted table;
  a zero write does not invoke the hook.
- `ConsumerView.subscribe` now retries the transient frontier race internally.
  Use `subscribeOnce` when one-attempt behavior is needed. C `af_subscribe`
  likewise retries internally.

See the [full changelog](https://github.com/nriddick/antfarm/blob/v1.9.0/CHANGELOG.md),
[parallel-loop guide](https://github.com/nriddick/antfarm/blob/v1.9.0/docs/guide/parallel-loops.md)
and [C ABI documentation](https://github.com/nriddick/antfarm/blob/v1.9.0/docs/design/c-abi.md)
for contracts and migration details. Initialize versioned C options with their
provided default functions before setting fields.

## Validation and performance

The release candidate passed the full Linux correctness gate under WSL2 and
the native Windows integration matrix on an Intel Core i7-12700H, using
LDC 1.42.0 and DMD 2.112.1. Coverage includes native C/C++ ABI checks,
runtime-free linkage, the optional host, ThreadSanitizer lanes on Linux,
ordering, actor lifecycle, release-mode fatal contracts and examples.
Portable tooling tests passed: 227 tests, five skips. All nine native benchmark
harnesses built, and 48 C/D lifecycle allocation-accounting cases passed.

This host has one LLC and one Windows processor group; this pass does not
establish live multi-LLC or multi-group coverage. See the
[verification record](https://github.com/nriddick/antfarm/blob/v1.9.0/docs/development/rc-verification-2026-10-20.md)
for coverage and limitations.

The existing Ryzen 9 5900XT performance report is retained unchanged. New
measurements on the Windows host were stopped after substantial variation
also appeared in an unchanged reference binary; no new host baseline or
performance verdict is claimed.

Supported targets are Linux x86-64 and Windows x64, with DMD 2.112+ or
LDC 1.42+. This is a source release; build the libraries with the documented
toolchains.
